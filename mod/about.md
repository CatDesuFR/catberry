# Catberry's Mod Menu

A mod menu for Geometry Dash 2.2091.

Press **Tab** to open or close the menu.

## Features

- **Click Before Frames**: a click that comes up to N ticks too early still counts. It's applied on the first tick it can jump or hit an orb. Every saved click is written to `CBF-LOGS.txt` in the mod's save folder.
- **Pointercrate cheat indicator**: green when only allowed hacks are on, orange when a "sometimes allowed" hack is on, red when a hack Pointercrate doesn't allow is on (or was on during the attempt).
- **Live console**: shows everything the mod logs (toggles, saved clicks, startpos switches, errors).
- **StartPos Switcher** (Q / E), labels (FPS, CPS, best run, run from, noclip accuracy and more), and many hacks in the Global, Player, Level, Bypass and Creator tabs.

Each hack has a coloured dot showing its Pointercrate status (from Pointercrate's "Allowed Mods/Programs" sheet).
